# Asal Sayı Kontrolü

### Projenin Amacı Nedir?
Python'da fonksiyonlar ve döngüler kullanarak bir sayının asal olup olmadığını belirlemek.

### Program Ne İşe Yarar?
Sayıların asal olup olmadığını kontrol eder ve 2 ile 20 arasındaki asal sayıları ekrana yazdırır.

### Program Nasıl Çalışır?
1. `is_prime()` fonksiyonu kontrol edilecek sayıyı alır.
2. Sayı 2'den küçükse `False` döndürür.
3. Sayının kareköküne kadar olan bölenleri kontrol eder.
4. Tam bölünme varsa `False`, yoksa `True` döndürür.
5. Asal sayılar ekrana yazdırılır.

### Kullanılan Python Yapıları Nelerdir?
- `def`, `return`
- `if`
- `for` döngüsü
- `range()`
- `int()`
- `%` ve `**` operatörleri
- `True`, `False`
- `print()` ve `end`

### Programın Beklenen Çıktısı Nedir?
```text
2 3 5 7 11 13 17 19
```

### Program Nasıl Çalıştırılır?
Python IDLE üzerinden `.py` dosyası açılır ve F5 tuşuna basılır.
